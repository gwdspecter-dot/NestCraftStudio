# NestCraft Studio

**NestCraft Studio** — модульная САПР-система (CAD) для параметрического 3D-проектирования корпусной мебели. Разрабатывается как открытый и расширяемый аналог «Базис-Мебельщик» на современном стеке **Python 3.10+**, **PyQt6**, **build123d** (OpenCASCADE) и **PyOpenGL 3.3+**.

---

## 🚀 Ключевые возможности

### 🪵 1. Параметрическое моделирование панелей
- **Базовые типы деталей**: вертикальные (боковины, перегородки), горизонтальные (полки, горизонты, цоколи) и фронтальные (фасады, задние стенки).
- **Свободная ориентация**: поддержка углов поворота в пространстве ($R_x, R_y, R_z$) с возможностью редактирования в панели свойств.
- **Отрисовка и триангуляция**: B-Rep твердотельное ядро OpenCASCADE с асинхронной триангуляцией в пуле потоков (`GeometryService` / `QThreadPool`), исключающей зависания интерфейса.

### 🔲 2. Кромкооблицовка и расчёт пильных размеров
- Назначение кромки на 4 торца детали (`top`, `bottom`, `left`, `right`) или пакетная облицовка всех 4 сторон.
- Интеграция с каталогом: толщина кромки подтягивается автоматически из базы данных.
- **Автоматический расчёт пильных размеров под раскрой** по отраслевым стандартам (ГОСТ / Базис-Мебельщик):
  $$L_{\text{saw}} = L - T_{\text{left}} - T_{\text{right}}$$
  $$W_{\text{saw}} = W - T_{\text{top}} - T_{\text{bottom}}$$
- Отображение пильных габаритов в режиме реального времени в панели свойств детали.

### 🔩 3. Автоматическая расстановка крепежа по стыкам
- **Детекция стыков (`Ctrl+H`)**: автоматическое определение зоны контакта двух смежных панелей и расчёт осей сверления.
- **Библиотека пресетов (`Tab`)**:
  - Евровинт (Конфирмат 7×50 мм)
  - Шкант деревянный (8×30 мм)
  - Эксцентриковая стяжка (Minifix / Rastex)
  - Полкодержатели
- **Защита от брака**: интеллектуальный алгоритм `check_hole_groove_collision` предотвращает пробитие паза задней стенки (ХДФ), автоматически смещая крепёж в безопасную технологическую зону.
- **Устранение копланарных артефактов**: цилиндры присадки вычитаются с гарантированным вылетом ($0.5\text{ мм}$ overshoot), предотвращая возникновение нулевых мембран в B-Rep геометрии.

### 📚 4. Локальный каталог материалов и фурнитуры (SQLite)
- Встроенная реляционная база данных `data/catalog/nestcraft_catalog.db`.
- **Справочники**:
  - Листовые материалы (ЛДСП, МДФ, ХДФ, Фанера, Массив) с плотностью, текстурами и ценами за м².
  - Кромочные ленты (ПВХ, АБС, меламин, акрил) с толщиной, шириной, образцами декора и ценой за метр.
  - Мебельный крепёж со схемами сверления (торец / пласть, диаметры и глубины, рекомендуемый шаг).
  - Поставщики и категории.
- **Браузер библиотеки (`Ctrl+Shift+M`)**:
  - Поиск, фильтры по типу и толщине.
  - Полноценные CRUD-операции: создание, редактирование и удаление позиций каталога.
  - Назначение материала или кромки на выделенную деталь в один клик.

### 📐 5. 3D-Вьюпорт и видовые экраны
- **Режимы отображения**:
  - `Заливка (Solid)` — гладкая модель с затенением по Фонгу.
  - `Каркас (Wireframe)` — полигональная сетка.
  - `X-Ray` — прозрачный режим с отображением скрытых граней светло-серым цветом.
- **Стандартные проекции**: 3D Изометрия (`F5`), Спереди (`F1`), Сверху (`F2`), Слева (`F3`), Справа (`F4`), Сзади.
- **Инструменты контроля**:
  - 📏 «Рулетка / Измерения» (`M`) с привязкой к рёбрам и вершинам.
  - 🎯 Интерактивное перемещение мышью (`G`) и дискретный сдвиг стрелками клавиатуры с настраиваемым шагом (1 мм, 10 мм, 16 мм, 50 мм, 100 мм).

### 💾 6. Управление проектом и Undo/Redo
- Полная история операций: многоуровневая отмена и повтор (`Ctrl+Z`, `Ctrl+Y`) для перемещений, смены размеров, материалов, кромки, присадки и создания деталей.
- Формат файла проекта **`.b3d` (v0.0.6)** с полной обратной совместимостью для ранних версий.

│       ├── fastener_repo.py # Репозиторий крепежа

│
├── ui/                      # Графический интерфейс на PyQt6
│   ├── splash.py            # Экран загрузки (SplashScreen) с прогресс-баром
│   ├── main_window.py       # Главное окно, меню, тулбары, горячие клавиши
│   ├── viewport.py          # 3D виджет OpenGL (Core Profile 3.3, шейдеры, камера, пикинг)
│   ├── dialogs.py           # Диалоги создания панели и ручной присадки
│   ├── catalog_browser.py   # Окно библиотеки материалов, кромок и крепежа с деревом групп

## 🛠 Установка и запуск

### Системные требования
- **ОС**: Windows 10/11, macOS (12+) или Linux (Ubuntu 20.04+, Debian, Fedora, Arch)
- **Python**: версия **3.10** или выше
- **Видеокарта**: поддержка **OpenGL 3.3 Core Profile**

### 1. Клонирование / подготовка проекта
```bash
cd NestCraft
```

### 2. Создание и активация виртуального окружения
- **Linux / macOS**:
  ```bash
  python3 -m venv venv
  source venv/bin/activate
  ```
- **Windows (PowerShell)**:
  ```powershell
  python -m venv venv
  .\venv\Scripts\Activate.ps1
  ```
- **Windows (CMD)**:
  ```cmd
  python -m venv venv
  venv\Scripts\activate.bat
  ```

### 3. Установка зависимостей
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

> **Примечание по `build123d`**:
> Пакет `build123d` автоматически устанавливает бинарные сборки ядра OpenCASCADE (`ocp`). Дополнительной компиляции C++ не требуется.

### 4. Запуск программы
```bash
python main.py
```

## ⌨️ Горячие клавиши (Shortcuts)

| Сочетание | Действие |
|:---|:---|
| **Ctrl + N** | Создать новый пустой проект |
| **Ctrl + O** | Открыть проект (`.b3d`) |
| **Ctrl + S** | Сохранить проект |
| **Ctrl + Shift + S** | Сохранить проект как… |
| **Ctrl + Z** | Отменить последнее действие (Undo) |
| **Ctrl + Y** | Повторить отменённое действие (Redo) |
| **Ctrl + D** | Дублировать выделенную деталь |
| **Ctrl + H** | Установить крепёж по стыку (режим сопряжения) |
| **Tab** *(в режиме стыка)* | Переключить пресет крепежа (конфирмат / шкант / эксцентрик) |
| **Колесо мыши** *(в режиме стыка)* | Изменить количество крепежей на стыке |
| **Esc** | Выход из режима крепежа / рулетки / сброс выделения |
| **Ctrl + Shift + M** | Открыть библиотеку материалов, кромки и крепежа |
| **G** | Начать перемещение детали курсором мыши |
| **M** | Включить / выключить измерительную рулетку |
| **Delete** | Удалить выделенный элемент |
| **F1** | Проекция спереди (XY) |
| **F2** | Проекция сверху (XZ) |
| **F3** | Проекция слева (ZY) |
| **F4** | Проекция справа (ZY) |
| **F5** | 3D изометрический вид |
| **Стрелки клавиатуры** | Сдвиг детали вдоль осей с выбранным шагом |
